# ⚔️ Морський Бій: UCUP 2026

![Іконка гри](assets/icon.png)  
*Класичний морський бій з сучасним інтерфейсом*

**Battleship UCUP** — це сучасна версія легендарної гри «Морський бій».  
Розставляй свій флот, стріляй по противнику та топи його кораблі!

## ✨ Основні можливості
- Класичні правила морського бою (10×10 поле)
- Інтелектуальний ШІ (`smart` режим)
- Приємна графіка та звукові ефекти
- Повністю портативна версія (.exe) — працює без встановлення Python
- Легке налаштування через `config.py`

## 🚀 Як запустити гру

### Windows (рекомендовано)
1. Завантаж `battleship_ucup.exe` з розділу **Releases**
2. Запусти файл подвійним кліком
3. Готово! Антивірус може видати попередження — це нормально.

### Linux
```bash
# 1. Клонуй репозиторій
git clone https://github.com/твій-нік/battleship-ucup.git
cd battleship-ucup

# 2. Встанови залежності
sudo apt update
sudo apt install python3-pygame python3-pip libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev

# або через pip
pip install pygame

# 3. Запусти гру
python3 main.py
Примітка: Для найкращої продуктивності на Linux використовуй Python 3.10–3.12.
🎮 Управління

Ліва кнопка миші — розставляти кораблі / стріляти
Права кнопка миші — повертати корабель під час розстановки
R — перезапустити гру
Esc — вийти

🛠️ Налаштування
У файлі config.py можна змінити:

Розмір екрану (SCREEN_WIDTH, SCREEN_HEIGHT)
FPS
Розмір поля (BOARD_SIZE)
Рівень ШІ (ai_level)
Увімкнути/вимкнути експериментальні твіки

🔧 Якщо виникають баги або лаги
Поширені проблеми та рішення:

Гра не запускається / чорний екран
Переконайся, що всі файли в папці assets/ на місці
Запусти з консолі: python main.py і подивись помилку

Лаги / низький FPS
Зменш FPS у config.py до 30–45
Закрий інші важкі програми
Онови драйвери відеокарти
